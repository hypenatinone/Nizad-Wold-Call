# Nizad World Call — Android
Projeto Android nativo inicial em Kotlin + Jetpack Compose.

## Gerar APK
Envie o conteúdo desta pasta para a raiz do repositório GitHub. Depois abra Actions e execute “Build Android APK”. Quando terminar, descarregue o artefacto `Nizad-World-Call-debug`.

## Estado
Esta é uma primeira versão visual navegável. O formulário de entrada é demonstrativo; não autentica contas reais. Mensagens, chamadas de vídeo, transmissões e publicações entre utilizadores ainda exigem backend, armazenamento, regras de segurança e integração com serviços próprios. Não coloque palavras-passe nem chaves privadas no código.
